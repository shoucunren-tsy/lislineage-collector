# 采集人手册（非技术版）

这份给不用命令行的人看。会用 Python 的可以直接看 `SKILL.md`。

## 你会拿到什么

一个任务目录，长这样：

```
B01_张三/
├── TASK.md              任务说明与清单
└── fenghuiling/
    ├── profile.csv
    ├── sources.csv
    ├── career.csv
    ├── papers_cn.csv
    ├── papers_intl.csv
    ├── activities.csv
    ├── relations.csv
    ├── books.csv
    ├── rejects.csv
    ├── audit.csv
    ├── manifest.json
    ├── report.md
    └── evidence/
```

一位学者一个文件夹。分到几位就做几个文件夹，不要合并。

任务包放在哪个盘、哪个文件夹都行，按你自己电脑的习惯来。

开工前先到 lislineage.com 搜一下姓名：**已经有页面的学者跳过、不做**。看一眼就行，不用反复核对。

## 怎么填表

用 WPS 或 Excel 打开 CSV 直接填。**先选中整列 → 设置单元格格式 → 文本**，再开始录入。否则会出现：

- `2021-03` 被自动改成 `2021/3/1`；
- `0000-0002-1825-0097` 被吃掉前导零；
- `10.1234/abcd` 被当成科学计数。

已经改错了：撤销，或把该列设成文本后重新录入。

### 三条底线

1. **一行一个对象**。一行一篇论文、一段经历、一次活动。
2. **不要插列、不要改列名、不要调列顺序**。校验器按表头认列。
3. **单元格里不要按回车**。需要多句用「；」连接。

### 保存

- 菜单：文件 → 另存为 → 选「CSV UTF-8（逗号分隔）」。
- 不要选「CSV（逗号分隔）」以外的 GBK 编码，否则中文会变乱码。
- 不要另存为 xlsx。校验器只认 `.csv`。
- 文件名不要改，不要加「最终版」「(1)」。

## 每条记录怎么写出处

以一篇中文论文为例：

1. 打开期刊官网的目次页，找到这篇。
2. 在 `sources.csv` 新增一行：`S012,期刊官网,一手,某某学报2021年第3期目次,某某学报编辑部,https://...,2026-10-21,evidence/S012.html,`
3. 在 `papers_cn.csv` 新增一行，`source_id` 填 `S012`。
4. `excerpt` 复制目次页上能证明这条的那句话，比如「冯惠玲, 某某某. 档案记忆的理论构建[J]. 档案学通讯, 2021(3): 5-12.」——不要只写标题。
5. 浏览器里按 Ctrl+S 保存页面到 `evidence/`，文件名 `S012.html`。

出处不是「我查过」，是「别人点开这个链接能看到这句话」。

## 被引次数怎么填

| 你看到的 | 怎么填 |
|---|---|
| 页面上写着「被引 12」 | cited=12，cited_status=verified |
| 聚合页写着 12，但点不进原始库 | cited=12，cited_status=recorded_value |
| 页面上明确写「被引 0」 | cited=0，cited_status=verified_zero |
| 页面没有这个信息 | cited 空，cited_status=unknown |
| 页面打不开/要登录/被拦截 | cited 空，cited_status=blocked |

**千万不要因为查不到就填 0。** 校验器会直接报错。

## 检索审计怎么填

每查一个渠道，加一行 `audit.csv`：

- 渠道名：`知网作者检索`、`学院官网`、`微信公众号`
- 检索式：你实际输入的内容或 URL
- 返回多少条、去重后多少条
- 有没有翻到最后一页
- 没翻完/被拦截 → `open`，并写原因

零结果也要写一行，原因写「检索式无结果」。这样下一个人不会重复劳动。

## 查过但不要的怎么办

写进 `rejects.csv`。比如搜到一篇同名作者的文章：

```
X003,fenghuiling,paper,10.1234/xxxx,档案信息化研究,同名不同人,作者单位为某师范大学，研究方向为档案保护，与本人类别不符,rejected,
```

这条比多收一篇还值钱——下一批不会重复判断。

## 自查

### 有 Python

在任务包目录执行：

```
python scripts/validate_package.py "B01_张三的目录"
```

看到「校验通过」再交。有错误按提示逐条改，错误编号会指出文件和行。

### 没有 Python

用 Chrome/Edge 打开工具包里的 `checker/index.html`，把你负责的批次文件夹整个拖进去。页面会列出问题。

注意：浏览器自查只覆盖常见问题，最终以维护者跑脚本为准。

## 常见报错

| 报错 | 原因 | 怎么改 |
|---|---|---|
| 表头不一致 | 改了列名/顺序，或用了 xlsx | 用模板重新复制表头 |
| 编码不是 UTF-8 | 另存成了 GBK | 另存为「CSV UTF-8」 |
| source_id 不存在 | 写了 S012 但来源表没有 | 补来源行，或改对编号 |
| 作者列表不含该学者 | 题录挂错人 | 核对后改归属或移到 rejects |
| cited 与状态冲突 | 未知填了 0 | 清空数字，改状态 |
| 审计未闭合 | 没翻到最后一页也没写原因 | 补 note 或翻完 |
| 出现绝对化表述 | 报告写了「全部收齐」 | 改成边界描述 |

## 交付

**每位学者的文件夹单独压成一个 zip 发回**：右键该学者文件夹 → 发送到压缩文件。一位学者一个压缩包。微信、网盘、邮件都行。

**不要**：

- 把所有 CSV 平铺成一个文件夹；
- 把几位学者压进同一个 zip；
- 改文件名或加副本后缀；
- 只发论文表不发来源表；
- 删掉空表（空表保留表头）。

## 查不到就停

一本书的编号、一个出版日期、一个被引次数，搜上 5 到 10 分钟还找不到，就别再搜了。在表里留空或写 unknown，去报告的「边界与缺口」记一句，接着做下一条。反复搜同一个东西只是浪费时间。

## 时间与质量

宁可少收一条，不要错收一条。错一条要花几倍时间回查。

拿不准的统一进 `rejects.csv` 的 `pending`，在报告里点名，不要自己拍板。
